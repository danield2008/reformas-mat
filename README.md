# Reformas Mat

Web estática responsive para Reformas Mat, especializada en reformas de baños y cocinas en Castellón y alrededores.

## Publicar con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Pulsa **Save** y espera unos minutos.

La URL esperada será: https://danield2008.github.io/reformas-mat/

## Antes de publicarla para clientes

- En `index.html`, cambia `const WHATSAPP_NUMBER='34600000000';` por el número real de WhatsApp, con prefijo internacional y solo dígitos. El número actual es un ejemplo provisional.
- Las imágenes son de inspiración y no deben presentarse como obras propias.
- Añade los datos de contacto reales, aviso legal y política de privacidad antes de captar solicitudes.
- El formulario prepara el mensaje en WhatsApp; el usuario debe confirmar el envío desde la aplicación.
